# ととのい黄金比

「サウナ〇分 + 水風呂〇分 + 外気浴〇分」の内容と、その日の「ととのい度」や体調を記録し、
**自分だけの黄金比(最もととのう時間配分)** をデータから見つけて提案する Web アプリです。

## 特化型AIとしてのポイント

汎用の対話AIは、あなたの体や、使う施設の水風呂の温度を知りません。このアプリは、
自分の記録そのものを学習データにして次の2段階で提案します。

1. **黄金比(集計)**: ととのい度4以上のセッションの平均時間配分を出します。水風呂14℃以下かどうか、施設ごと、でも分けます。
2. **予測モデル(機械学習)**: 時間配分と、睡眠・疲労・食事・温度から「ととのい度」を予測する回帰モデルと、「4以上になる確率」の分類モデルを学習します。今日のコンディションを固定して時間配分を総当たりし、予測スコアが最大の配分を提案します。

予測の信頼度は、交差検証で「平均点を答えるだけの基準」と比較して必ず画面に出します。
記録が少ないうちは(20件未満)モデルを使わず、集計の黄金比だけを使います。

## 機能

| 画面 | 内容 |
|---|---|
| 記録 | セットごとの時間入力、ストップウォッチ(押した区間の時間が自動で入る)、施設・室温・水風呂温度、睡眠・疲労度・食事、ととのい度(5段階)、メモ |
| 黄金比 | 全体 / 水風呂14℃以下と超 / 施設別の黄金比(時間配分の帯グラフと比率) |
| 予測 | 今日のコンディションから最適な時間配分を提案。サウナ時間ごとの予測の変化、候補一覧、決めた配分の評価 |
| 振り返り | ととのい度の推移、月別回数、セット別平均時間、カレンダー |

## 起動方法

Node.js 18 以上と、Python 3.10 以上が必要です。予測モデルが Python(scikit-learn)で動くためです。

```bash
npm run setup   # 初回だけ。Python の専用環境(.venv)を作ってライブラリを入れる
npm run dev     # 起動
```

表示されたURL(通常は http://127.0.0.1:8000)をブラウザで開きます。8000番が使用中なら、空いている次のポートが自動で選ばれます。
画面は同じサーバーから配信されるので、フロントエンドのビルドは不要です。

<details>
<summary>npm を使わずに起動する場合</summary>

```bash
python -m venv .venv
source .venv/bin/activate        # Windows は .venv\Scripts\activate
pip install -r requirements.txt
cd backend
uvicorn app.main:app --reload
```

</details>

専用環境(.venv)を使うのは、他のプロジェクトで入れた numpy や pandas とバージョンが衝突して起動できなくなるのを防ぐためです。
ただしグラフ(Chart.js)とフォントは CDN から読み込むため、画面の表示にはインターネット接続が必要です。

記録は `backend/sauna.db`(SQLite)に保存されます。別の場所を使うときは環境変数 `SAUNA_DB` にパスを指定します。

はじめて試すときは、ページ下の「サンプルを追加」を押すと架空の記録が60件入り、全機能を確認できます。
サンプルは自分の記録と区別され、いつでも一括削除できます。

    main.py       API とフロントエンドの配信

## API

| メソッド | パス | 内容 |
|---|---|---|
| GET / POST | `/api/sessions` | 記録の一覧(新しい順)/ 追加 |
| DELETE | `/api/sessions/{id}` | 記録の削除 |
| GET | `/api/analysis/golden` | 黄金比(全体・水風呂温度別・施設別) |
| GET | `/api/analysis/dashboard` | グラフ・カレンダー用の集計 |
| POST | `/api/predict` | 今日のコンディションから最適な配分を予測 |
| POST / DELETE | `/api/sample` | サンプルデータの追加 / 削除 |

`include_sample=false` を付けると、サンプルを除いた記録だけで分析・予測します。

## 既知の制限

- ととのい度は主観評価で、1人の記録は数十件程度です。モデルの予測はあくまで目安で、医学的な安全性を保証するものではありません(高血圧など持病がある場合は医師の指示を優先してください)。
- 認証がなく、全員が同じ記録を共有する作りです。複数人で使う場合はユーザー管理が必要です。
- サンプルデータは「サウナ約9.5分・水風呂約1.3分・休憩約11分がととのいやすい」と仮定して作った架空のものです。サンプルで出る結果は、実際のととのい方を表しません。
